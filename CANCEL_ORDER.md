# Cancel Order Feature

## User Story

As a customer, I want to cancel my order
so that I can receive a refund if I no longer need the product.

## Acceptance Criteria

1. Customer can view their orders.
2. Customer can select an eligible order.
3. Customer can click the Cancel Order button.
4. Customer receives cancellation confirmation.
5. The system displays refund information.
6. Shipped orders cannot be cancelled.
